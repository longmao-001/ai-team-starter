# 八页格式规范（写之前先读这一页）

本目录是「基础团队必备小套餐」：**八张角色页，换行业只改占位符**。八页必须长得一样，否则读者要学八种写法。

## 一页的固定结构（六段，顺序不许换）

```markdown
# <角色名>（<一句话类别>）

## 1. 一句话职务
## 2. 输入
## 3. 输出
## 4. 边界
## 5. 必备纪律
## 6. 三条「常见写歪」
```

## 每段必须写成什么样

| 段 | 必须包含 | 判据（写完自问） |
|---|---|---|
| 1 职务 | 对什么负责 + **不对什么负责** | 读者能说出"它不该管什么" |
| 2 输入 | 收什么才准开工、缺哪项就退回 | 缺项时的动作写死了，不是"视情况" |
| 3 输出 | 交付物形态 + **可核的验收串** | 验收串能 grep、能数、能对账 |
| 4 边界 | 不做什么、什么必须上报 | 上报项具体（哪三类风险、几小时内） |
| 5 纪律 | **只写指针**：指向哪份文件的哪一节 | 本页不出现纪律正文 |
| 6 反例 | 三条，每条「现象 → 后果 → 改法」 | 每条都能被同行认出来"这就是我" |

**第 6 段的呈现以表格为准**（四列：写歪｜现象｜后果｜改法）——三件事写在三个格子里，读者一眼能对上，也方便统稿比对。
用 `**✗**` 列表写同样三条内容**不算违规**，但同一份包里不要混用两种：统稿时统一改成表格，只改呈现、不动文字。

## 占位符（锁死四个，不许自创第五个）

| 占位符 | 替换哪类信息 |
|---|---|
| `{{ORG}}` | 组织 / 团队 / 机构名 |
| `{{DOMAIN}}` | 专业领域或业务线 |
| `{{DELIVERABLE}}` | 该角色交付的成品 |
| `{{RUN_PATH}}` | 一切盘符 / 内网路径 |

自创占位符会让扫描器多一条规则、多一个漏替换点。**四个套不上的信息，改写成类型词**（"某项目""某部门"），不造新占位符。占位符集合**恰好四个**：多一个少一个都不算过。

## 三条硬约束

1. **一页 ≤ 120 行**（含空行）。超了说明还没提炼——砍掉解释性文字，留动作。
2. **不出现工具细节**：怎么调用脚本、跑哪条命令属于技能文档，不属于角色页。角色页只写"必须做到什么"。
3. **不写"我们那套"**：不出现"我们团队一直""我们的经验是"。全部写成**对读者下命令**（你必须 / 不许 / 退回）。

## 落库前自检（五条，缺一不交）

- [ ] 六段齐全、顺序一致，标题层级只有 `#` 与 `##`
- [ ] 占位符只有那四个；`{{` 与 `}}` 成对
- [ ] 第 5 段全是指针，没有一段纪律正文
- [ ] 第 6 段恰好三条，每条都有"改法"
- [ ] 行数 ≤ 120；脱敏扫描过（跑 `90-tooling/sanitize_scan.py`，扫发布树）
