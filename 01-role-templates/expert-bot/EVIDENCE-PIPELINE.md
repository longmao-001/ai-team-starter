# 证据流水线：从公开材料到专家档案

> 一句话：**先有出处，再谈性格。** 顺序反了，写出来的就是面具。
> 五个步骤，每步有「不通过就不许往下走」的判定。

---

## 第 1 步 选人（2–4 位）

| 要求 | 判定 |
|---|---|
| **公开可查** | 有论文 / 教材 / 公开演讲 / 访谈 / 公开争论中的至少三类 |
| **跨传统** | 优先选**互相争论过**的两派；至少跨 2 个国别或 2 个代际 |
| **不重叠** | 不选同一师承、同一学派、同一机构 |

- **禁忌**：只选同一学派 → 你拟合出的是「一个学派的平均值」，不是能在评审里吵架的专家。
- **不通过判定**：如果 3 个人从没在公开场合对同一问题有过不同意见，这组人写不出「典型分歧」，换人。

## 第 2 步 取料（每位四类，每类至少一条）

1. **论文**（含综述、方法学文章），优先开放获取；记录 DOI/URL；
2. **公开演讲 / 访谈 / 播客**；拿不到正文就登记「标题 + 年份 + 载体」，标**低置信度**；
3. **教材 / 专著章节**——看他把什么写成「基础」，这最能暴露他轻视什么；
4. **公开争论**——谁反驳谁、反驳什么。**这是信息量最大的一类材料。**

> 争论为什么最值钱：自述会美化自己，反驳只暴露真实判断标准。他选择在哪个点上还手，就是他真正的优先级。

## 第 3 步 提纯（六件事，逐条落表）

| 提取项 | 写成什么 | 例子形态 |
|---|---|---|
| **方法论主张** | 他反复强调的原则 | 「凡结论先记账不确定性」 |
| **论证习惯** | 先问什么、怎么反驳、爱用什么例子 | 「先问样本怎么来的，再问结果」 |
| **侧重 / 轻视** | 决定判断风格的取舍 | 「重可复算，轻新颖性」 |
| **表达特征** | 句长、情绪、术语密度、口头禅 | 「短句，少形容词，爱用反问」 |
| **典型分歧** | 跟同行的经典争论 + 为什么争 | 「与 X 争的是该不该机械校正」 |
| **盲点** | 方法在什么条件下失效 | 「采集流程未验证时会给干净结论」 |

**每提取一项，必须立刻记下：支撑它的材料编号 + 置信度。** 不许事后补。

## 第 4 步 证据分级与置信度归一

**材料级**：高 = 多篇独立材料一致 + 有原文直引；中 = 单一来源或需间接推断；低 = 二手转述/推测，只能当假设。

**判断级归一**（防止「凭印象定置信度」）：
- 先验 0.5；
- 每份**高**材料似然 ×2；**中** ×1.3；**低** ×1.0；**冲突材料** ×0.5；
- 归一后：≥0.8 高 / 0.5–0.8 中 / <0.5 低。

> 这不是精密统计，它的唯一作用是**逼你把"我觉得"变成"哪几条材料"**。

## 第 5 步 反证与双档

- **反证（硬要求）**：每位至少一条**削弱现有画像**的材料，写明：推翻了哪条判断、置信度如何调整、改成了什么说法。
- **两份高置信材料互相矛盾**：不调和，**登记为「存在两种传统」**，两条都留。
- **双档交付**：
  - `REFS.md`——参考人物清单 + 出处 + 每条支撑哪条判断 + 置信度（内部研究笔记）；
  - `PERSONA.md`——只收公开证据能支撑的内容；
  - `INFERRED.md`——本役推断、团队设定、未施测条目。**物理分开存放。**

### REFS.md 结构（直接套用）

```
# {{席位}} · 参考人物与出处（REFS v{{N}}）
性质：内部研究笔记，不对外透露参考对象

## 一、选人逻辑
| 代号 | 方向 | 国别 | 代际 | 公开载体 | 为什么选 | 与谁对照 |

## 二、材料清单
| 编号 | 出处（作者 (年份) 标题. 刊/URL/DOI） | 支撑哪条判断 | 置信度 |

## 三、反证材料
| 编号 | 推翻了什么 | 改成了什么 | 置信度变化 |

## 四、未覆盖
{{语言圈、代际、取不到的材料——如实写"公开材料不足"，不许编}}

## 五、版本历史
| 版本 | 日期 | 改了什么 | 为什么 |
```

---

## 一条验收线

把 `PERSONA.md` 交给一个不认识这个领域的人，他应该能：
1. 说出这个专家**会先问什么**；
2. 说出他在**哪一步会拒答**；
3. 找到**反驳他的地方**（反证 + 盲点）。

三条答不出，回去补料，不许定稿。
