# 01 角色模板

三类角色的创建模板。**先看下面这张选择表，再动手。**

| 维度 | 功能 agent | 专家 bot | 管理 bot |
|---|---|---|---|
| 核心问题 | 这件事**怎么办成** | 这件事**怎么看** | 这群人**怎么跑** |
| 输入 | 结构化（文件/字段） | 开放（问题/材料） | 任务与状态 |
| 输出 | 固定形态的交付物 | 判断、方向、追问 | 派工、收口、台账 |
| 好坏判据 | 可否机器校验 | 是否经得起同行追问 | 在途是否可见、是否收得回 |
| 常见病 | 输出漂移、越界编数据 | 变成"人格面具"、正确但无用 | 自己下场干活、台账腐烂 |
| 模板 | [`functional-agent/`](functional-agent/README.md) | [`expert-bot/`](expert-bot/README.md) | [`manager-bot/`](manager-bot/README.md) |

## 三条通用规矩

1. **一个 bot 只扛一个主目标。** 挂两个主目标，两件都会打折。
2. **角色卡里必须有一句"不许做什么"。** 只写职责不写边界的角色卡，迟早越权。
3. **角色卡是给人看的，不是给模型念的咒语。** 写完后念给别人听，对方能说出"它下一步会做什么"，才算写清。

## 建一个角色的顺序

1. 从选择表定位类型 → 2. 抄对应模板 → 3. 逐个填占位符（每个占位符旁有填错的例子）→ 4. 用反例清单自查 → 5. 干跑一次真实任务，把跑崩的地方回写成新的边界条款。
