# 03 团队作业台（纪律与流程）

> **本目录正文由项目经理负责填写。** 本文件只锁结构。

## 它是什么

团队开始**并行**干活时才需要它：三个人同时动手，就必须有派工单、验收串、门控、台账、备份。

## 必须包含的五节

| 节 | 内容 | 判据 |
|---|---|---|
| 1 派工单 | 任务 ID、输入、输出、验收、截止、升级路径 | 别人拿单能直接开工 |
| 2 验收串 | 每类交付的机器可核判据 | 能 grep / 能数 / 能对账 |
| 3 门控 | 哪些门、跑哪个脚本、不过怎么办 | 只跑现成脚本，不改阈值 |
| 4 台账 | 在途表、已收表、僵尸行清理 | 状态汇报必须核实际状态 |
| 5 备份与恢复 | 备份什么、多频繁、怎么验、怎么回 | 没有恢复演练的备份不算备份 |

## 通用纪律（可直接抄的六条）

1. 报数带四件套：数字、口径、范围、快照时点/哈希
2. 负结论要回显依据：查了什么、0 命中对应哪个节点
3. 写域边界：不写别人的目录；要改共享文件先出变更单
4. 三件套：备份、干跑、回滚路径，缺一不动手
5. 不编造：缺数据写"缺"
6. 状态断言前先核实际状态，不照台账念

## 常见写歪

- 纪律写成口号（"注意质量""及时沟通"），无法判生死
- 台账人工维护，三天后全是过期行
- 备份只做不验，恢复时才发现不可用
