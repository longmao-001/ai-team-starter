# 派工与收口

> 派工单写不好，后面所有事都是补救；收口不核，前面所有事都白做。

## 派工单：六件套

```
任务 ID: T-{{YYYYMMDD}}-{{NN}}
owner: {{谁干}}
objective: {{一句话：要达成什么结果，不是要做什么动作}}
output: {{绝对路径 + 文件形态}}
tool guidance: {{用哪个 skill / 脚本 / 参考哪份已有产物}}
boundaries: {{不许碰什么：别的目录、别人的文件、门的阈值}}
acceptance:
  - [可执行] {{能复制执行的验收串}}
due: {{YYYY-MM-DD HH:MM}}
blocked_by: {{任务ID 或 none}}    能否并行: {{是/否 + 理由}}
```

## 每一件的「写对了」标准
| 要素 | 写对的标准 | 常见错法 |
|---|---|---|
| objective | 读的人知道「什么算达成」 | 「处理一下 XX」 |
| output | 绝对路径 + 形态，能直接打开 | 「整理成文档」（哪个文件？） |
| tool guidance | 点名 skill/脚本/参照物 | 「自己看着办」 |
| boundaries | 点名文件、点名目录 | 「注意不要影响别人」 |
| acceptance | 可执行命令 + 期望值 | 「确认无误」「合适」 |
| due | 具体到小时 | 「尽快」 |

## acceptance 的写法（这一段值得单独练）
**正例**：
```
- [可执行] grep -c "^## " spec.md  == 8
- [可执行] python -c "print(len(open('x.md',encoding='utf-8').read().split()))"  在 800–1200
- [可执行] sha256 与 D4E1…（64位）一致
- [可执行] 脚本 check_schema.py exit 0，输出含 "PASS"
```

## 反例与改法

| 反例 | 为什么不行 | 改法 |
|---|---|---|
| 「格式无误」 | 谁判格式？ | 列出必须存在的 8 个二级标题 |
| 「已核对数据」 | 核了哪些？ | 给出总数与逐行相加的校验值 |
| 「与上一版一致」 | 上一版哪个 sha？ | 附旧版 sha 与新 sha |
| 「内容完整」 | 无法验收 | 列出必须覆盖的 N 个条目名 |

**边界值要写死**：`≥12` 还是 `==12` 给出的验收结果完全不同。写区间就写两边。

## 在途表（贴群里）

```
| 任务ID | owner | 状态 | 跑到哪 | 卡在哪 | due |
|---|---|---|---|---|---|
| T-0301-07 | 写稿bot | RUN | 已出初稿 | 等事实核查 | 03-01 22:00 |
```

**必填「卡在哪」**，写 `none` 也要写。这一栏空着，说明没人真的在看。

## 收口：四条硬规则

## 1. 不吃自报
只认可核的交付：行数、字段、脚本输出、diff、sha。执行方说「已处理、无新动作」，不算交付，哪怕他说的是真的。

## 2. 半改不收
半改的文件比没改更危险——它容易被后人当成新口径引用。列出还缺哪几项，等齐了再收。

## 3. 数字对不上，两列都写
回执里的数与盘上实测不一致时，列「它报 vs 实测」，并给两种可能解释让对方选一（例：算的是别的文件 / 文件在回执后被改过）。**不要自己挑一个顺手的解释。**

## 4. 验收串要防误命中
选不会被合法语境污染的串。裸数字、编号、编号位号都会撞。用长串锚定，别为了凑 0 去改坏数据内容。

## 收口后的三件事（同轮做完）

1. QUEUE 行改 DONE，指回产物路径
2. MANIFEST 追加一行：时间 / 交付物 / 依据谁的话 / sha
3. 如果这次暴露了新规则，写进坑注册表（不要只在心里记）

## 常见缺口清单（派工前扫一眼）

- [ ] 发布类单：有没有预注册（预期计数 + 预期 sha）？事后补的只能标「事后登记·非预注册」
- [ ] 清单类单：核了「子目录件数 + 顶层件数 vs 全目录实测」吗？只核 sha 核不出「只写了顶层」
- [ ] 换文件类单：显示框比例 vs 内容比例核了吗？不成比例时先问清是改尺寸还是补白，别靠拉伸凑满
- [ ] 复现类单：两次同输入结果不一致要按复现性问题处理，不取平均、不挑一遍
- [ ] 盲评类单：先各自冻结分数 sha，再 diff，最后才映射标签。顺序倒置等于放弃盲法

## ✗ 常见错法

✗ 验收写「确认无误」。收口那一刻没人能判过没过，于是要么信自报，要么返工重开。
