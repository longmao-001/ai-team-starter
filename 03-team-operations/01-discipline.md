# 全队通用纪律

> 八条底线。不是最佳实践，是**不做就会出事**的那种。每条给「为什么」和「怎么查」——只给「要重视」的规则没人执行。

## 一、报数：四件齐全才算数

任何数字（行数、条数、件数、体积、比例）必须带齐：

1. **数** —— 多少
2. **口径** —— 怎么数的（MiB 还是 MB、含不含子目录、LF 还是 CRLF）
3. **范围** —— 哪一批、哪个目录
4. **快照** —— `sha256:` 全 64 位或写明截位，或时点 `HH:MM+08`

**为什么**：只给一个数、不给口径和时点，等于给了个传闻。两个人手上都不是同一份文件时，永远查不出谁对。

## 报哈希与报行数

**报哈希的三条**（公共判据）：
- 必须带算法名与位数：`sha256:` 前 16 位 / `sha256:` 64 位全值 / `md5:` 32 位全值，写清是哪一种
- 不许裸写十六进制，不许只写「…」而不说明截了几位
- 跨人对账一次给两种（sha256 + md5），省一轮往返

**报行数也要写口径**：同一份文件，LF 计数 / 非空行 / split 含尾空段，三个数都真实存在，写哪个都要说明。

**对不上时先核口径，再谈冲突**：两个哈希不相等，第一种可能是**口径不同**（算法或位宽），第二种才是文件变了。顺序判断反了，会把两个都对的数判成打架。

## 二、负结论必须能看见依据

报「0 条」「无异常」「查过了」「没有受影响」时，必须写清：

- 读的是哪个文件 / 哪条命令
- 该路径是否存在（`Test-Path` 结果）
- 查证类的写检索式与平台

**为什么**：一个「0」和「忘了做」长得一模一样。审计工具读错路径还静默报 0，比没有审计更危险——它给的是假绿灯。

## 三、交付回执：格式固定

```
status: 完成 | 部分完成 | 阻塞
结论: ≤5 条，每条一句
产物: 绝对路径 + 字节数 + sha256:<64位全值>
验收: 逐条给命中数
```

「已完成」三个字不算交付。可核交付 = 能 grep 到的行数、能重算的计数、能比对的哈希、能跑的脚本输出。**自报一律不算。**

## 四、写域与批准门

- 写自己领域：自由
- 写别人领域：先报告，再暂停，等裁定。越界后第一件事是**告知**，不是补救
- 移动 / 删除 / 改名用户的文件：必须当轮批准，且批准要落在对话里
- **自己的规则不能给自己的动作授权**：写了「每周自动归档」，不等于拿到了移动文件的许可
- 复制不需要批准，移动需要

## 五、三件套：任何写操作之前

| 步 | 动作 |
|---|---|
| 1 备份 | 留旧版 + 记旧 `sha256:`（全 64 位） |
| 2 干跑 | 只读 / `--dry-run` / 小样本 |
| 3 回滚 | 写明怎么退回，且**真的演练过**（≤3 步） |

**没有 `.bak` 就不算走完三件套**。备份是三件套里唯一不可事后补救的一步：干跑能补、回滚能补、备份补不了。

## 六、门控

- 只跑**现成脚本**，不改阈值、不放宽
- **跳过 ≠ 通过**；`exit 2` 不等于 PASS
- 脚本报 FAIL 先分清是产物问题还是匹配问题（大小写、旁路文件），不照抄退出码

## 七、不编造

- 查不到写 `NOT_AVAILABLE` 或 `未见`，并写明检索范围
- **「查了但没命中」和「没查」必须分开写**
- 不推测、不「应该可以」、不用相近条目冒充
- 数字不许自补，引用不许自引——缺口单列

## 八、状态断言带快照

「全清」「无在途」「已归档」「正在跑」这类话，必须带**快照 + 时点**，或当场查一次实况。

**为什么**：台账状态不等于实况。QUEUE 里写着 RUN 的，可能早就做完了。有一张过期的在途表，比没有更糟——它让你以为进度已知。

**判断「不是我改的」之前**，先查三样：文件 mtime、群会话回执、旧新 sha256。同一个人的两个会话互不知情，别把自己的动作当成外部事件。

## 九、数字与状态：现取现算

件数、字节、行数、占位符次数、HEAD——一律当场取。引用既有 HEAD 前先 `git rev-parse HEAD`；抄来的数不进发布门，门里出现的数必须是脚本输出。

两次报出不同的数：先报差值（它报 vs 实测）与两种解释，别挑顺手的那个。

证据（同一周四次「自报 ≠ 实况」）：行数 1,026 → 1,056（手算漏 30 行）；件数 22 → 25（含 3 件运行残留）；占位符 0/1/2 → 全文 2/2/3（口径「正文」与扫描器「全文」不一致）；HEAD 三次报的是旧值，落后 1–3 个提交。

四次都不是撒谎，全是没现取。口径与实况打架时，先对齐口径，再谈冲突。

## ✗ 常见错法

✗ 报数只报数字。省了口径与快照，读的人只能把它当传闻用——四个人四个数时，谁也证不了谁错。
