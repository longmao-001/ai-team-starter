# 实体名单格式示例（本文件只是格式示例，真名单不要提交）
#
# 复制成 90-tooling/rules/denylist.local.txt，把下面示例行换成你项目里的真实词条。
# 本文件已被 .gitignore 排除的只有 denylist.local.txt —— 本示例文件会进仓库，
# 所以这里只能放"明显是示例"的词。
#
# 格式：`类别:词条`，一行一条。类别自定义，命中后会在报告里显示成 denylist_<类别>。
# 匹配方式：大小写不敏感的子串匹配（不做正则，避免误伤与爆炸）。
#
# 建议至少建这几类：

name:示例人名甲
name:示例人名乙
org:示例机构名
proj:示例项目代号
host:示例主机名
money:示例金额写法
code:示例内部编号前缀

# 为什么名单不进仓库：
# 名单本身就是敏感信息。把真名写进公开仓库的配置文件，等于换个地方泄露。
# 所以这一层只能在本地跑，CI 只跑结构规则层（路径/IP/邮箱/密钥/证件号）。
