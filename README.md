# AI 团队搭建手册（模板 + 教程）

一套**填空即用**的 AI 员工团队搭建包：三类角色模板、知识库/图谱/RAG 骨架、团队作业台纪律、从零搭队检查表。

> 这本手册只回答一个问题：**你手上只有一台空电脑，下一步做什么？**

- 全部内容都是模板与步骤，不含任何真实人名、机构名、未发表数据、内网路径。
- 占位符写成 `{{ROLE_NAME}}` 这种形式，照填即可；填完可以用 `90-tooling/scaffold.py` 一键生成团队目录。
- 公开前必须跑 `90-tooling/sanitize_scan.py`，结果是 BLOCK 就不许推。

---

## 一、30 秒决策：你要建哪一类？

| 你想要的 | 选这类 | 它的典型形态 | 判断标志 |
|---|---|---|---|
| 一个能反复干同一件事的**执行者** | 功能 agent | 虚拟研究员、审稿助手、数据整理员 | 有**固定输入 → 固定输出**，交付物可验收 |
| 一个能就专业问题**跟你讨论、给方向**的**专家** | 专家 bot | 某学科教授型顾问、行业老兵 | 无法预先规定输出格式，价值在判断与追问 |
| 一个**管人管事**的**协调者** | 管理 bot | 项目经理、制片人、主编 | 负责判型、派工、收口、门控、台账，自己不产出正文 |

**选错的表现**：把专家 bot 当执行者用（让它按模板填空，输出变得又长又空）；把管理 bot 当专家用（它开始裁学术结论，越权且不可复核）。

## 二、最小可用团队是几个？

**三个就够跑起来**：1 个管理 bot + 1 个功能 agent + 1 个专家 bot。

- 管理 bot 负责**谁在跑、跑到哪、卡在哪**；
- 功能 agent 负责**能验收的产出**；
- 专家 bot 负责**判断与方向**，防止团队自嗨。

> 先跑通三个，再加。每加一个角色，都要能回答"它补上了哪个具体缺口"。答不上来，就是加了个聊天窗口。

## 四、5 分钟快速开始

```bash
# 1. 复制本仓库到本地
git clone <this-repo> ai-team && cd ai-team

# 2. 复制一份配置，改成你的团队
cp 90-tooling/examples/team.config.example.json team.config.json

# 3. 生成目录骨架 + 渲染模板
python 90-tooling/scaffold.py --config team.config.json --out ../my-team

# 4. 干跑一次脱敏扫描（公开前必做）
python 90-tooling/sanitize_scan.py --root ../my-team
```

第 3 步生成的东西不是终点，只是**目录和占位符**。真正的工作是填 `{{...}}`——每个占位符旁边都写了"填什么、填错会长什么样"。

## 五、三条最容易写歪的地方

1. **把角色卡写成岗位说明书**：写"负责知识库建设"没人知道下一步做什么，要写"每周一从 X 取数，产出 Y，由 Z 验收"。
2. **纪律写成口号**：写"要注意质量"等于没写。要写"门控只跑现成脚本，跳过不等于通过"这种能判生死的句子。
3. **示例写成炫耀**：示例要写"我们第一次是怎么写错的，改成什么样"，不是"我们做得多好"。
