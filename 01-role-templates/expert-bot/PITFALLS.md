# 10 个坑（现象 + 原因 + 改法）

> 都是真踩过的。写教程的标准：**能让人少踩一次**，所以每条必须具体到"看到什么现象、为什么、改成什么"。

### 坑 1：从任务里的行为反推性格
- **现象**：因为某次派工里 bot 表现谨慎，就在档案里写「他性格谨慎」。
- **原因**：任务中的表现是**角色行为**——它由派工单、验收口径、上下文决定，不是由人决定。
- **改法**：角色行为单独登记为「角色行为」，不算人格。人格只从真人的**公开材料**拟合。档案里出现"在这次任务中他……"就是错位。

### 坑 2：形容词当性格
- **现象**：「严谨、开放、有批判性、善于沟通」，一行一个词，很整齐。
- **原因**：形容词没有反例，无法判定 PASS/FAIL，也无法执行。
- **改法**：每个形容词必须接「做过什么」+ 作者-年份。写不出，降为「推断，低置信度」，移入 `INFERRED.md`。

### 坑 3：用类型学生成性格
- **现象**：先算出生日期/做完 MBTI，然后写出「他因此不爱冒险」。
- **原因**：类型学**不能生成**材料里没有的性格，只能给**已观察到的**行为命名和组织。
- **改法**：先有行为证据，再用类型学命名；冲突时以公开证据为准；对外不出现类型学词汇。

### 坑 4：只选同一学派
- **现象**：三个人方法一致，档案写得很顺，但一到评审就只会点头。
- **原因**：同源材料拟合出的是「学派平均值」，没有分歧点，就没有判断力。
- **改法**：选人强制跨传统、跨国别或跨代际；没有公开争论过的组合，换人。

### 坑 5：没有反证，画像不可反驳
- **现象**：所有材料都支持所有结论，档案像宣传稿。
- **原因**：只找了支持性材料——这是确认偏误，不是研究。
- **改法**：每位至少一条削弱材料，写明推翻了哪条、置信度怎么变。**一份不能被反驳的画像就是人设宣传。**

### 坑 6：二手转述当原文
- **现象**：出处写「某综述提到」「业内普遍认为」。
- **原因**：无法核 = 等于编。
- **改法**：查不到作者-年份+可点开链接的，一律不写。找不到就如实写「公开材料不足」。
- **注意**：「查了但没命中」和「没查」要分开记账——0 命中的检索词要写检索式和日期。

### 坑 7：置信度凭印象
- **现象**：同一条判断，今天写"高"，明天写"中"，理由都是"感觉材料挺多的"。
- **原因**：没有可复算的算法，置信度就变成装饰。
- **改法**：用归一算——先验 0.5，高 ×2 / 中 ×1.3 / 低 ×1.0，冲突 ×0.5；≥0.8 高 / 0.5–0.8 中 / <0.5 低。算完再写。

### 坑 8：把制度设定读成性格冲突
- **现象**：「四个人四种评分尺子，所以他们在互相攻击」。
- **原因**：团队分工、席位差异、评分口径属于**制度层**；它是设计出来的，不是长出来的。
- **改法**：制度层与人格层分开登记。判断一个分歧前先问：是方法不同，还是任务不同？

### 坑 9：把工具契约写进人格卡
- **现象**：人格档案里出现派工模板、验收口径、文件路径规范。
- **原因**：把专家写成了工单，人格降级。
- **改法**：人格档案只写"想什么、怎么说、什么不做"；工具契约留在 skill / 角色卡里。

### 坑 10：专家永不拒答、永不改判
- **现象**：任何问题都答，且答案前后永远一致。
- **原因**：真实专家有边界、会被人说服、会在自己阵营里挑错——这些正是判断力的来源。
- **改法**：
  - 写死「拒答条件」和越界固定回复；
  - 写「被哪类论证说服就改判」的规则（例如：被更强的证据设计说服，而不是被语气说服）；
  - 写「对自己阵营也挑错」的具体例子（来自公开材料）。
